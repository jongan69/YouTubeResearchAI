How It Works

A multi-stage research pipeline that treats video as a primary source and builds cited, verified analysis around it.

📥 Download Video → 🎙️ Transcribe (Whisper) → 🎯 Domain Detection → 🔍 Literature Search → 🧪 Evidence Synthesis → 📝 Cited Report

Production-Grade Research Features

Everything you need to turn passive video watching into active academic research.

🔬

Automated Literature Search

Queries arXiv, Semantic Scholar, CrossRef, and OpenAlex simultaneously. Scores and ranks results by citation count, recency, and keyword relevance. All APIs are free — no paid subscriptions required.

✅

Claim Verification

Compares every substantive claim against peer-reviewed literature. Assigns confidence levels: well-supported, plausible, contested, speculative, or opinion. Surfaces contradictions between sources.

📝

Proper Citations

Inline numbered references with formatted bibliography in APA, Chicago, or IEEE style. Citations are validated against fetched metadata — hallucinated references are automatically pruned. Every reference includes DOI and URL.

🎓

Domain-Aware Research

Five academic domain profiles (Computer Science, Medicine, Social Sciences, Humanities, Natural Sciences) automatically tailor search strategies, preferred databases, and evaluation standards to the field.

🔄

Iterative Deep Research

Multi-pass research mode identifies gaps in the literature coverage, runs targeted searches to fill them, and re-verifies claims against the expanded evidence pool. Converges when no new sources are found.

📊

Multi-Source Synthesis

Cross-reference multiple videos on the same topic. Identifies consensus themes, points of disagreement, unique contributions per source, and literature gaps across all sources.

🖼️

Visual Content Analysis

Extract and analyze keyframes from video. Vision AI identifies equations (with LaTeX reproduction), diagrams, code snippets, data charts, and on-screen citations that never appear in the transcript.

🏗️

Provider-Agnostic

Works with OpenAI (GPT-5.5), Anthropic (Claude), Google (Gemini), and any OpenAI-compatible endpoint (Groq, DeepSeek, Ollama). Features degrade gracefully when unsupported by a provider.

📋

Complete Audit Trail

Every search query, retrieved source, and selection decision is logged to JSONL. Reports include a Research Methods section documenting the methodology, databases searched, and limitations.

🎯

Structured Research Output

Beyond the polished Markdown article: structured JSON with executive summary, thesis, key ideas, timeline, glossary, evidence assessments, study questions, and a 7-day study plan.

🛡️

Graceful Degradation

Every optional feature fails gracefully. An API outage doesn't crash the pipeline — it continues with what's available and logs the issue. Backward compatible with zero-flag default behavior.

💰

Zero Cost Research APIs

All four academic databases are completely free. The only costs are your AI provider's standard API rates for transcription and report generation. No subscriptions, no hidden fees.

Quick Start

Go from zero to a cited research report in under 2 minutes.

# 1. Clone and install
git clone https://github.com/jongan69/YouTubeResearchAI.git
cd YouTubeResearchAI && npm install

# 2. Add your API key
cp .env.example .env
# Edit .env: set OPENAI_API_KEY=sk-your-key

# 3. Add a YouTube URL
echo "https://www.youtube.com/watch?v=VIDEO_ID" > links.txt

# 4. Run PhD-grade research
npm run research --research --verify --citation-style apa

Usage Examples

From basic study guide to PhD-grade research — one flag away.

Basic Study Guide

$ npm run research

Cited Research Report

$ npm run research --research --citation-style apa --max-sources 10

PhD-Grade Deep Research

$ npm run research --research --research-depth deep --verify --citation-style apa --max-sources 20 --reasoning-effort high --max-output-tokens 32000

Multi-Source Synthesis

# links.txt contains 2+ related videos
$ npm run research --research --verify --synthesis

Visual Analysis + Research

$ npm run research --research --vision --max-frames 30

What You Get

Every run produces a complete research package.

outputs/run-YYYY-MM-DD-HHMMSS/
