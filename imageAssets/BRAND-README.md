# YouTube Research AI — Logo Package

## Concept

The mark combines three ideas:

- **Play triangle** — the YouTube/video source
- **Research brackets** — structured analysis, citations, and technical tooling
- **Verified check** — evidence-backed claim verification

The design is intentionally distinct from YouTube's official logo while remaining immediately understandable.

## Palette

- Research Ink: `#090D15`
- Deep Slate: `#141C2B`
- Paper White: `#F7F9FC`
- Evidence Coral: `#FF4D4D`
- Verification Cyan: `#59DDF7`
- Muted Gray: `#94A0B2`

## Recommended usage

- GitHub README / website light backgrounds: `youtube-research-ai-horizontal-light.svg`
- Dark hero sections: `youtube-research-ai-horizontal-dark.svg`
- App icon / avatar: `youtube-research-ai-mark.svg`
- Browser favicon: `youtube-research-ai-favicon.svg`
- One-color printing or engraving: `youtube-research-ai-mark-monochrome.svg`
- GitHub social preview: `youtube-research-ai-social-card.png`

## Clear space

Keep at least one check-badge radius of empty space around the mark. Do not rotate, stretch, recolor individual parts, or place the primary mark over a visually busy background.
